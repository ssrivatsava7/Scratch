## Projects

### 🎵 Dopamine 2.0 - YouTube Audio & Video Player
**Status**: ✅ Fully Implemented and Functional

A Flutter application for streaming YouTube audio and video content.

**Features**:
- Search and play YouTube audio
- Full video playback support
- High-quality streaming (up to 720p)
- Smart content filtering
- Intuitive UI with play/pause/stop controls

**Location**: `dopamine2_0/`

**Quick Start**:
```bash
cd dopamine2_0
flutter pub get
flutter run
```

**Documentation**: See [dopamine2_0/README.md](dopamine2_0/README.md) and [YOUTUBE_IMPLEMENTATION_PROGRESS.md](YOUTUBE_IMPLEMENTATION_PROGRESS.md)
